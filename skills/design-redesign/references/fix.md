# Fix mode

One improved version of the target, in place.

- Work down the diagnosis in order. Keep behaviour, data, routes and factual copy. Ask before changing what a control does or adding claims.
- Fix structure before surface: reorder by importance, merge or remove redundant elements, and switch to the right component type (a table that should be a list, a modal that should be inline). Then spacing and type. Colour comes last.
- Remove more than you add. Most bad screens carry too many boxes, labels and explanations.
- Use the existing tokens and components. If a value you need doesn't exist, such as a denser row height, add it to the token system instead of writing a literal.
- Screenshot the result at the same size and with the same data as the baseline, extremes included. Put before and after side by side and check every diagnosis line. Make one correction pass, then stop.

Report the diagnosis, what changed for each line, the before and after screenshots, and anything left undone.
